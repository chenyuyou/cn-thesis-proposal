# 配套《评阅与写作说明.md》

## 角色和生成条件
当用户要求教学范文或双文档时，与正式Word同步生成；正文放实际研究计划，教学解释和审核提醒放说明。现有用户资料和官方模板的权限优先。其他场景按请求选择，不强制增文件。

## 应含内容
1. 适用对象、使用步骤和来源/授权范围；区分通用逻辑和案例特定内容。
2. 逐节说明“这一节回答什么—范文如何论证—为何这样写—常见误区—自查”；尊重学校表格。
3. 问题—内容—材料—分析—预期成果—时间的对应；不能回答的问题和数据、文献实际状态。
4. 按研究类型举迁移例子，说明什么能学、什么不能照搬；不虚构真实数据或访谈。
5. 逐节验收清单、引用/格式/伦理/审批检查；分开必须修改、可选改进与待导师确认。
6. 两文档变更一致性：公式、章节、图号、数字、资料状态及链接一致；无验证则明确标注。

不要把某一高校课程时限或文献数量转成普遍标准；不要把某个实例的具体论文题目、政策、样本、符号、单位当作默认素材。不得包含学生个人信息、未授权文献PDF或伪造签章。
