# 案例与质性研究

明确问题、案例边界、选取理由、比较逻辑、材料能否取得以及研究者与案例关系。典型、关键、极端、便利等选择均可，但应如实说明理由与限制，不把便利样本包装成理论抽样。

列明拟用资料（访谈、档案、公开记录等）和访问权限；在未核验时写成计划或待确认，不虚构案例资料完整、来源均可取得或研究现象已发生。公开来源并不自动保证资料完整、成本可控或伦理风险低，需依据具体任务评估；涉及公开个人信息仍需考虑隐私和许可。多源互证有帮助但不保证真实或因果。按研究传统选择编码、主题分析、过程追踪、文本解释或其他方法，不强制统一编码模型。记录相反证据、解释竞争、适用范围和匿名/知情同意安排；不能预称访谈完成、理论饱和或代表全部组织。
