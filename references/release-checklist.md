# 发布与后续维护检查清单

- 明确著作权与开源许可证，确认作者/贡献者授权；不可把他人的教材、论文PDF、学校标识、校表、真实学生开题、带个人信息的会话或私有路径直接公开。
- 示例优先人工撰写的虚构材料，明确标为合成数据，不将其当真实研究成果。完整标杆范文需要独立权利与事实审查；本技能默认不内置本项目Word或PDF。
- 排查个人姓名、学号、签名、隐藏域、修订、文档属性、绝对路径、密钥、环境与Git历史。
- 逐方法验证路由和真实输出：本科/学硕/专硕/博士、因果/问卷/案例/应用诊断、资料不足、审阅只读、Word复杂模板、参考文献缺失、无转换工具。
- 为每项脚本写最小测试与限制说明；不在README宣称适配所有高校表格、100%识别学术错误、保证因果或“无损”。
- 未经用户明确要求，不建立仓库、选择许可证、添加远程或推送；用户批准发布后仍须核对具体发布范围和内容。
